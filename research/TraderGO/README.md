# TraderGO-anteckningar

Öppna `research/` som valv i Obsidian (**Open folder as vault**). Här ligger projektets
anteckningar i numrerade mappar (00 Dashboard … 09 Archive), mallar och bilagor. Egna
`.canvas`-filer går bra här; de följer JSON Canvas och fungerar på både macOS och Windows.

`research/registry.md` är facit för hypoteser och beslut. Anteckningarna får länkas och utvecklas,
men ändrar aldrig ett beslut (se skillen `forskningslogg`). Personliga Obsidian-inställningar
committas inte; se `.gitignore`.

TraderGO Universe visar valvet tillsammans med resten av projektet men ändrar aldrig något här.
